### How to install
```bash
git clone https://github.com/Xi-v/slowfetch.git
cd slowfetch
./slowfetch
```
And then you can add it to aliases.
**Example:**
```bash
alias slowfetch='cd *diretory it's installed in* && ./slowfetch && cd "$OLDPWD" >/dev/null'
```
